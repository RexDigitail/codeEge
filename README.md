# Приложение для анализа распространения заражения

## Описание
Приложение с графическим интерфейсом для анализа распространения заражения. 
Оно принимает файл с координатами точек заражения, находит очаги (источники) 
и прогнозирует дальнейшее распространение.

## Требования
- Python 3.8+
- tkinter
- numpy
- matplotlib
- scikit-learn
- scipy

## Установка зависимостей
```bash
pip install numpy matplotlib scikit-learn scipy
apt-get install python3-tk  # Для Linux/Debian
```

## Запуск приложения
```bash
python infection_analysis_app.py
```

## Использование

### 1. Загрузка данных
Нажмите кнопку "Загрузить файл с координатами" и выберите файл в одном из форматов:
- **TXT**: Каждая строка содержит X и Y координаты, разделенные пробелом или запятой
- **CSV**: Две колонки с координатами X и Y
- **JSON**: Массив объектов или массивов с координатами

Пример формата TXT:
```
100 100
105 98
98 103
250 200
255 198
```

Пример формата JSON:
```json
[
    {"x": 100, "y": 100},
    {"x": 105, "y": 98},
    [250, 200],
    [255, 198]
]
```

### 2. Настройка параметров кластеризации
- **Eps (радиус)**: Максимальное расстояние между точками для объединения в один кластер (по умолчанию 50.0)
- **Min Samples**: Минимальное количество точек для формирования кластера (по умолчанию 5)

### 3. Поиск очагов заражения
Нажмите кнопку "Найти очаги заражения". Приложение:
- Выполнит кластеризацию точек методом DBSCAN
- Определит центры кластеров (очаги заражения)
- Отобразит результаты на карте слева

### 4. Прогноз распространения
Нажмите кнопку "Спрогнозировать распространение". Приложение:
- Построит модель распространения от найденных очагов
- Покажет зоны заражения на разных временных шагах (1, 3, 5)
- Отобразит прогноз на правой панели

### 5. Информация
В нижней панели отображается:
- Информация о загруженном файле
- Количество найденных очагов
- Координаты центров очагов
- Параметры прогноза

## Формат выходных данных
После анализа вы получите:
- Визуализацию карты зараженных точек с выделенными кластерами
- Координаты центров очагов заражения
- Радиусы очагов
- Прогноз распространения с зонами заражения

## Пример тестовых данных
В комплекте идет файл `test_coordinates.txt` с тестовыми данными, содержащими 3 очага заражения.

## Алгоритм работы

1. **Кластеризация DBSCAN**: Группировка точек заражения в кластеры
2. **Определение очагов**: Вычисление центров кластеров как источников заражения
3. **Модель распространения**: Расчет зон заражения на основе:
   - Начального радиуса очага
   - Скорости распространения (30 ед./шаг)
   - Временных шагов прогноза

## Примечания
- Для корректной работы требуется графический интерфейс (X11/Wayland)
- При работе в headless режиме используйте виртуальный дисплей (Xvfb)
